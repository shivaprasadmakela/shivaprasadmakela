- Earlier: SSE-based in-app notifications, RBAC user management, LeadCollector services

**🎓 learnNow** *(MVP in progress)*
A React/TypeScript/Vite learning platform for developers — roadmaps, structured paths, and hands-on practice.
- Auth, dashboard, home, paths, and roadmap modules on a feature-driven frontend architecture
- CSS Modules + CSS custom properties theme engine
- **StudyConsole**: a full-screen topic reader with a table of contents, markdown content, code blocks, and embedded quiz questions, with auto-completion once all subtopics are done
- **iAmAdmin**: a course-authoring module for configuring paths/topics/subtopics/quizzes through a draft → preview → publish flow, feeding straight into the catalog and StudyConsole
- Avatar customization: DiceBear seed+style avatars, randomly assigned on signup, editable later via a style picker

**Feature goals for learnNow**
- [ ] Ship the MVP: auth, dashboard, roadmap browsing, and the StudyConsole reader end-to-end
- [ ] Launch iAmAdmin so course content can be authored and published without touching code
- [ ] Public beta launch, cross-promoted through GitHub and YouTube
